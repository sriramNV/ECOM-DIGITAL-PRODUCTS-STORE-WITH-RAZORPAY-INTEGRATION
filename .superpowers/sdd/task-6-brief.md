# Task 1.6: Install shadcn/ui primitives

**Plan:** Plan 01 — Foundation & Project Setup
**Depends on:** Task 1.4 (Tailwind v4 tokens), Task 1.5 (utils.ts with cn())
**Produces:** shadcn/ui component primitives available to all subsequent plans

## Files to Create

- `apps/web/components.json` (shadcn config)
- `apps/web/components/ui/button.tsx`
- `apps/web/components/ui/input.tsx`
- `apps/web/components/ui/badge.tsx`
- `apps/web/components/ui/card.tsx`
- `apps/web/components/ui/skeleton.tsx`
- `apps/web/components/ui/dialog.tsx`
- `apps/web/components/ui/dropdown-menu.tsx`
- `apps/web/components/ui/table.tsx`
- `apps/web/components/ui/toast.tsx`
- `apps/web/hooks/use-toast.ts`

## Steps

### Step 1: Add shadcn/ui dependencies
```bash
pnpm add class-variance-authority clsx tailwind-merge lucide-react --filter web
```
(clsx and tailwind-merge may already be installed from Task 1.5)

### Step 2: Initialize shadcn/ui
```bash
cd apps/web
npx shadcn@latest init
```

When prompted:
- Style: Default
- Base color: Slate
- CSS variables: Yes
- Tailwind v4: Yes

This creates/updates `components.json` and adds shadcn config to globals.css.

### Step 3: Install component primitives
```bash
npx shadcn@latest add button input badge card skeleton dialog dropdown-menu table toast
```

Expected: All component files created under `apps/web/components/ui/`.

## Notes

- This is a CLI-driven task — files are generated by shadcn CLI, not handwritten
- shadcn uses `cn()` from utils.ts (created in Task 1.5)
- shadcn components rely on Tailwind tokens from globals.css (Task 1.4)
- After installation, verify `pnpm dev` still starts
- The init command may ask for interactive input — provide Default/Slate/Yes/Yes
