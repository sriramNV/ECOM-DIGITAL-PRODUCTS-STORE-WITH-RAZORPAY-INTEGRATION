## Description

```
In this video, I build a complete digital products e-commerce platform from scratch — a place to sell ebooks, software, templates, courses, and any digital download. Full admin panel, Razorpay integration, file delivery, and Docker deployment.

What's built:
• Next.js 15 storefront with App Router, React 19, TypeScript
• Product catalog with search, category filtering, sorting, pagination
• Shopping cart with Zustand (persisted, synced server-side on checkout)
• Razorpay payment integration — real orders with HMAC signature verification
• Admin dashboard with stats, product CRUD, order management
• File upload system with versioning, signed download URLs
• Rate-limited file downloads with download tracking (3/hr per user)
• User accounts with order history, bulk download all
• Dark/light theme with localStorage persistence
• Docker Compose deployment (PostgreSQL, Redis, MinIO S3)
• Security: CSRF protection, rate limiting, security headers, path traversal protection

Tech Stack:
• Next.js 15 (App Router, TypeScript strict)
• React 19, Tailwind CSS v3, shadcn/ui
• Zustand + TanStack Query
• PostgreSQL 16 + Prisma ORM
• NextAuth v5 (credentials + Google OAuth)
• Razorpay Orders API + Webhooks
• Redis 7 (rate limiting, caching)
• MinIO (S3-compatible storage)
• Docker Compose (4 services)
• pnpm workspaces
```
